# Developer Rules & Guidelines

## Modern Design Principles
- Use clean, contemporary UI elements with rounded corners, soft shadows, and smooth transitions
- Apply consistent spacing using CSS Grid and Flexbox layouts
- Implement a cohesive color palette focusing on white background with #e86b41 (Burnt Sienna) accents
- Maintain visual hierarchy with appropriate typography and contrast ratios
- Prioritize mobile-first responsive design approach

## Code Standards
- Write semantic HTML with proper document structure
- Use CSS custom properties (variables) for consistent theming
- Implement modular CSS with BEM methodology or similar naming convention
- Write clean, readable JavaScript with ES6+ features where appropriate
- Follow DRY (Don't Repeat Yourself) principle
- Use meaningful variable and function names
- Add concise comments for complex logic only
- Organize code in logical sections with clear separation of concerns

## Animation & Interaction Guidelines
- Implement smooth performance-optimized animations using CSS transforms and opacity changes
- Use requestAnimationFrame for complex JavaScript animations
- Ensure animations respect user preferences (prefers-reduced-motion)
- Create non-synchronized animations to avoid repetitive motion
- Maintain 60fps performance for all interactive elements
- Add hover and focus states for all interactive elements

## Performance Considerations
- Optimize images for web use (appropriate sizes and formats)
- Minimize HTTP requests
- Use efficient CSS selectors
- Defer non-critical JavaScript
- Implement lazy loading where appropriate
- Keep bundle sizes small

## Accessibility Requirements
- Ensure proper semantic HTML structure
- Implement proper ARIA attributes where needed
- Maintain keyboard navigability
- Provide alternative text for images
- Ensure sufficient color contrast ratios
- Use proper heading hierarchy

## Avoiding Development Loops
- Read the full PRD and checklist before starting any implementation
- Break complex tasks into smaller, manageable subtasks
- Implement functionality first, then refine styling
- Test features incrementally rather than waiting until completion
- Set clear completion criteria for each task
- When facing challenges, document the issue briefly and move to the next task if possible
- Return to challenging issues with fresh perspective after completing other tasks
- Regularly review completed work against PRD requirements
- Focus on completing one section fully before moving to the next major section

## Quality Assurance
- Test across multiple browsers and devices
- Validate HTML and CSS syntax
- Verify all links and forms function properly
- Ensure all animations perform smoothly
- Review accessibility compliance
- Confirm responsive behavior meets requirements
